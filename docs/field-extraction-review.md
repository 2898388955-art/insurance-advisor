## 二、已修正的 3 处错误

| 产品 | 条款原文 | 原抽取 | 修正为 |
|---|---|---|---|
| H05 | 出生满 28 天至 65 周岁 | NULL | 0 |
| H06 | 18 周岁至 55 周岁 | NULL | 18 |
| T07 | 出生满 30 天至 65 周岁 | NULL | 0 |

原因：PyMuPDF 降级文本把「18 周岁」「出生满28天」拆到了上一行，规则只拿到上限。
**这类错误能通过逐字校验**——quote 合法，但值不完整，说明「引文校验」不能替代「字段语义校验」。


执行时点项目只产出了 14 份，但当前仓库 34 份全部为 MinerU 产物。
这 18 份降级输入不是数据问题，是时序问题；H05 的识别错误大概率由此产生。
