## 三、为什么这些端口

| 端口 | 说明 |
|---|---|
| 3307 | 本机已有 MySQL 8.4.9 占 3306，错开避免冲突 |
| 6380 | 已有容器 `hm-redis` 占 6379 |
| 9000/9001 | 对象存储 S3 / 控制台，本机空闲 |
| 19530/9091 | Milvus 标准端口 |
| 2379 | etcd 只在容器网络内使用，不映射到宿主机 |

## 四、常用命令

```bash
# 启动全部
docker compose -f deploy/docker-compose.yml up -d

# 只看某个服务
docker compose -f deploy/docker-compose.yml up -d milvus

# 状态
docker compose -f deploy/docker-compose.yml ps

# 日志
docker logs -f ia-milvus

# 彻底清理（会删数据卷，慎用）
docker compose -f deploy/docker-compose.yml down -v
```

## 五、数据落盘位置

Docker Desktop 的数据目录已迁移到 `D:\dev-runtime\docker`（通过目录联接
`C:\Users\Admin1\AppData\Local\Docker` 指向），所以以上所有 volume 的实际数据都在 D 盘。
